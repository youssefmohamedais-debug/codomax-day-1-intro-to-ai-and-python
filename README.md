دفتر تفاعلي تعليمي على **Google Colab** يشرح أساسيات الذكاء الاصطناعي وتعلّم الآلة، ويتضمن تمارين عملية وبرامج بسيطة بلغة Python للمبتدئين.

---

## 📌 أهداف المشروع

1. تعلّم أساسيات **الذكاء الاصطناعي (AI)** و **تعلّم الآلة (ML)**.
2. التمييز بين **AI** و **ML** و **Deep Learning**.
3. استكشاف تطبيقات واقعية للذكاء الاصطناعي.
4. ممارسة مفاهيم البرمجة في Python: المتغيرات، الحلقات، الدوال، القوائم.
5. كتابة برامج Python بسيطة ومناسبة للمبتدئين.

### بنية الدفتر
- **شرح نظري:** جدول الفرق بين AI / ML / Deep Learning مع أمثلة
- **أساسيات Python:** المتغيرات، الحلقات (`for` / `while`)، الدوال، القوائم
- **5 برامج تطبيقية:**
  1. برنامج تعريفي يحسب العمر بعد 10 سنوات
  2. فحص زوجي / فردي باستخدام دالة
  3. طباعة الأرقام 1–10 مع مجموعها
  4. تحليل قائمة درجات (متوسط، أعلى، أدنى)
  5. لعبة تخمين الرقم باستخدام `while`

## 🚀 كيفية التشغيل على Google Colab

1. افتح [Google Colab](https://colab.research.google.com)
2. من القائمة: **File ← Upload notebook** واختر ملف `intro_ai_python_colab.ipynb`
3. شغّل كل خلية بالضغط على زر التشغيل ▶ أو من القائمة: **Runtime ← Run all**
4. للتسليم أو المشاركة: **File ← Share** للحصول على رابط، أو **File ← Download** لتحميل الملف

## 📖 ملخص سريع: AI vs ML vs Deep Learning

| المفهوم | التعريف | مثال |
|---|---|---|
| **AI** | محاكاة الذكاء البشري لحل المشكلات | المساعد الصوتي Siri |
| **ML** | فرع من AI يتعلّم الأنماط من البيانات | تصنيف البريد المزعج |
| **Deep Learning** | فرع من ML يستخدم شبكات عصبية متعددة الطبقات | التعرّف على الوجوه |

**العلاقة:** Deep Learning ⊂ ML ⊂ AI
